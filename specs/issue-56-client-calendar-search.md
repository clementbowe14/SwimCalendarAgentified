# Google Calendar checks for invite searches

Use the provider on the active invite to check their connected calendar on both public availability endpoints. Return the existing public slot fields and error contract. Recheck the invite during a multi-day search and before returning results. A legacy instructor without a provider account has no possible calendar connection.

For weekly search, offer a time only if the same local start and end are available all four weeks. Evaluate each needed week once and use the same scheduling policy. Keep the calendar generation stable through the offer write transaction. A small public search budget limits concurrent calendar checks before they take lifecycle locks.

Exercise busy and disconnected calendars, public response privacy, provider outages, and later-week conflicts using synthetic Google responses.
